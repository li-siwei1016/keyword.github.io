# 传讯 · 单页版

模拟与「梦角」聊天的纯前端单页应用。无后端，全部数据保存在浏览器本地（localStorage + IndexedDB/localforage）。

## 两种部署方式

### 方式一（推荐）：只上传 `index.html`
`build/index.html` 是把 CSS 与全部 JS 内联后的**单文件版**，所有样式与逻辑都在这一个文件里。

1. 打开 GitHub 仓库 → `Add file` → `Upload files`
2. 把 `index.html` 拖进去 → `Commit changes`
3. 等 1～2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

> 注意：网页端上传**不会解压 zip**。不要上传压缩包，也不要把外层文件夹一起拖进去（会多一层目录，导致页面 404）。

### 方式二：结构化上传
想以后方便改代码，就上传下面这套目录（保持层级不变）：

```
index.html
css/styles.css
js/……（含 js/features/ 下的各个功能模块）
```

在 GitHub 网页端可以用 `Add file → Upload files` 一次性拖入 `index.html`、`css`、`js` 三个条目（拖文件夹会自动保留内部结构）。

## 目录结构

```

js/features/home.js         主页（相框、签名、时间问候、纪念日、主页主题）
js/features/diary.js        日记本
js/features/memo.js         备忘录（对方在聊天里提醒）
js/features/profiles.js     对象管理（多档案数据隔离）
js/features/moments.js      朋友圈（动态）
js/features/period.js       经期记录（日历视图）
js/features/link-status.js  链接状态（3 小时锁定）

js/features/slacking.js     摸鱼状态 + 摸鱼字卡（含分组）+ 摸鱼小记
js/features/chat-header.js  聊天顶栏（长按空白处唤出）与首次提示
js/features/decision-ask.js 询问 · 抉择
js/features/envelope.js     信件 · 信封投递
js/features/reply-library.js 字卡库（自定义回复）

js/features/call.js         视频通话

js/features/theme-editor.js 主题与外观
js/onboarding.js            使用前声明与新手引导
js/listeners.js             事件绑定
js/app.js                   启动入口
```

## 功能一览

- **主页**：头像（显示上传头像，双头像贴近、签名向中间收拢）+ 链接波纹 + 随机签名；第一行右侧为**拍立得照片堆**（无背景框，照片放大，单击「收拢再散开」轮换、照片完整展示、点击添加、长按更换 / 删除）；日期时间问候；**Ta 的手机**（心情 / 状态 / 摸鱼状态，点进去可看 Ta 的状态、Ta 的朋友圈、Ta 的信笺、心情手账、摸鱼小记）；相遇纪念日；聊天（有未读红点）/ 朋友圈 / 信件；字卡库 / 高级功能 / 设置。主题色、相框颜色与背景图可在「外观设置 → 主页主题」自定义。
- **聊天**：顶栏**默认收起，长按聊天界面空白处从顶部弹出**（首次使用有新手提示），保留 主页（最右侧）/ 会话 / 群聊 / 公告 / 日夜切换；链接状态 3 小时内锁定（四级为「云水泱泱」）；底栏为「让对方说话 · +（视频通话 / 相册 / 问一问 / 红包转账）· 输入框 · 表情 · 发送」。
- **红包 / 转账**：微信样式气泡、双方发送均带头像；我方发送时可自定义金额或选寓意金额（5.20 / 13.14 / 66.66…）；我方发出后 Ta 自行领取并回复，有 1% 概率退还；Ta 发来的红包我方点击领取，Ta 不再回复。
- **问一问**：答案选项每行一个，圆角边框 + 🍀 装饰。
- **朋友圈**：微信式封面（可下拉放大）、我方头像 72px、头像下为可编辑的自定义签名；支持点赞 / 评论，评论回复时间可在「聊天设置 → 节奏」调节（默认 30s）。
- **信件**：信封投递，寄出 / 收到分栏。
- **字卡库**：侧栏四大分支——「回复库 / 摸鱼管理 / 氛围感 / 公告」。**回复库管理**下的子标签（横向可滑动）依次为：**主字卡 → 颜文字 → 状态字卡 → Emoji → 表情库**；**摸鱼管理**下为 **摸鱼活动 → 工作地点**。颜文字为独立字卡库（点击插入输入框、长按删除、可批量添加）；状态字卡与摸鱼字卡均支持**一键去重（筛选重复词条并去除）**与**分组**（分组管理 / 分组筛选，与主字卡格式一致，批量导入时可直接选择分组）。
- **摸鱼状态**：Ta 会随机进入摸鱼状态，显示为「Ta 在 地点 活动」，主页「Ta 的手机」实时可见，「摸鱼小记」保留往日记录。
- **高级功能**：消息统计、悬浮音乐播放器、运势占卜、询问 · 抉择、经期记录（日历）、重要日、日记本、备忘录。
- **设置**：外观设置、聊天设置（含红包概率、朋友圈评论回复时间）、数据管理、对象管理（多档案切换，数据互不干扰）。

## 数据说明

- 数据只存在当前浏览器，换设备 / 清缓存会丢失，建议定期在「设置 → 数据管理」导出备份。
- 切换「对象管理」中的档案后，聊天、动态、设置等数据各自独立保存。
